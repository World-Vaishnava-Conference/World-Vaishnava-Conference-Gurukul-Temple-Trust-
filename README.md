# World-Vaishnava-Conference-Gurukul-Temple-Trust-
"World Vaishnava Conference Gurukul &amp; Temple Trust is a Government Registered Charitable Trust in Patiram, Dakshin Dinajpur, West Bengal, India. Dedicated to Gurukul education, temple development, Goshala, women's self-defense training, social welfare, cultural development and spiritual service for the benefit of society."
